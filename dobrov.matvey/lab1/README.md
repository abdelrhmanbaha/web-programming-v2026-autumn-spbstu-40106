# Лабораторная работа 1

## Задание

Создать постраничную навигацию. Элементы навигации должны располагаться по
центру страницы, а текст внутри них — по центру по двум осям. Активный элемент
должен отличаться цветом фона, а при наведении фон остальных элементов должен
изменяться

## Реализация

В HTML создан блок `div` с классом `.pagination`. Внутри него находятся пять
ссылок: стрелка назад, номера страниц и стрелка вперёд

- Блок навигации размещён по центру страницы с помощью Flexbox в `body`
- Элементы навигации имеют размер `40 × 40` пикселей
- Текст внутри ссылок выровнен по центру по горизонтали и вертикали
- Между элементами установлен отступ `6` пикселей
- Активная страница выделена синим фоном с помощью класса
  `.pagination__item--active`
- При наведении на ссылку её фон становится серым, а текст — белым

Стили вынесены в отдельный файл `styles.css`

## Запуск

Открыть `index.html` в браузере
